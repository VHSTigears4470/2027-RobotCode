## Navigation
The `main` branch of this repository only stores code that is stable and tested. All code may be found on their respective branch as per the branch.

**Branches**
- Feature Branches (feat/x)
- Refactor Branches (refactor/x)
- Milestone Branches (milestone/x)

**Pull Requests**
- Draft Pull Requests
    - Incomplete / In progress
    - Untested

- Open Pull Requests
    - Complete
    - Tested
    - Ready for review

**Issues**
- Feature Requests
    - To be completed
    - Refactor Changes
- Bugs
    - Logic Errors
    - Motor Config Changes
